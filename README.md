# Student Performance Predictor

A beginner-friendly Machine Learning project that predicts student performance based on study hours, attendance, previous marks, and assignment score.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- NumPy
- Matplotlib

## Features

- Takes student details as input
- Uses Machine Learning for prediction
- Predicts Pass or Needs Improvement
- Simple web interface using Streamlit
